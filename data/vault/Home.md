## How to Use This Vault

1. **Graph View**: Press `Ctrl/Cmd + G` to see the full knowledge graph. Nodes are color-coded by folder.
2. **Search**: `Ctrl/Cmd + Shift + F` for full-text search across all notes.
3. **Tags**: Use the tag pane to filter by `#pm-implication`, `#case-study`, `#framework`, `#india-context`, etc.
4. **Backlinks**: Every note shows backlinks — see which sessions and concepts reference each other.
5. **Mermaid Diagrams**: Render natively in Obsidian — no plugins needed.
